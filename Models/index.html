Gen5 CAD Material Audit — for the Design Team

Source: GEN5 V1 MAIN.step (exported 13 Aug 2026, AP214, Autodesk toolchain) · every number below read directly from the file, verified independently on two machines
The one-line finding: no part in this CAD has a weight, and 205 of 233 materials are an untouched default. The file stores materials + densities, never masses. Weight can only be computed from material × volume — so with the battery marked "Steel", the CAD "weighs" ~31 kg against the real, scale-measured 12.0 kg. Off by 2.6×.

What the design team should do

  1. Assign real materials to the red rows first — battery, pump, LIDAR, Herelink, GPS, connectors, capacitors, diodes. For purchased parts, the honest fix is a vendor-datasheet mass override in CAD rather than a density guess.
  2. Re-apply materials to every mirrored body. Mirrors silently reset to Steel in this toolchain — check each one after mirroring.
  3. Fix the two mislabelled screws (assigned Aluminum, named steel).
  4. Turn the four "80.5G DUMMY WEIGHT" names into real mass properties — the weight currently lives only in the part's name, which no software can read.
  5. Sanity target: after the pass, the assembly's computed mass should come out near the scale-measured 12.0 kg. If it doesn't, the materials are still wrong.
For the record: the flight simulation was never affected — it uses the measured 12.0 kg (and the weighed 0.55 kg UT gauge), and its accuracy was proven in flight. This audit is about making the CAD's own numbers trustworthy for the next design.
