Before the configuration is sealed

Eight items to resolve first

These came out of the logged values themselves, not the classification. The first one directly undermines the freeze; the rest are protections that are configured but not actually armed, or settings that need a written justification on file.

MOT_HOVER_LEARN= 2Blocks the freeze

This setting means Learn and Save. The autopilot will rewrite MOT_THST_HOVER — a Section 1 frozen parameter — by itself during normal flight. A freeze on the hover-thrust value cannot hold while this is set to 2. Set it to 1 (learn in RAM, do not save) or 0 before the configuration is sealed.

FENCE_TYPE= 1Protection gap

Only the maximum altitude fence bit is set. FENCE_RADIUS is stored as 300 m but the circular-fence bit (value 2) is not enabled, so lateral containment is not actually being enforced. If a horizontal boundary is part of the approved operating limitations, this must read 3 (altitude + circle) or include the polygon bit.

FENCE_ACTION= 0Protection gap

A fence breach is Report Only — the aircraft announces the breach and keeps flying. No automatic containment response is armed. Certification normally expects an RTL, Brake, or Land response here.

FS_GCS_ENABLE= 0Protection gap

The ground-control-station link failsafe is disabled. Loss of the telemetry link triggers no action. Confirm this is acceptable for the intended concept of operations, particularly for any beyond-visual-line-of-sight approval.

ARMING_SKIPCHK= 510084Verify & justify

Eight pre-arm check groups are being skipped (bits 2, 7, 11, 14, 15, 16, 17, 18). Each skipped check removes a barrier against launching with a defective sensor. Decode this against the ArduPilot 4.7 parameter reference and record a written justification for every bit, or clear them before freezing. Note that 4.7 replaced ARMING_CHECK with this inverted-sense parameter — a value carried over from an older configuration will not mean what it used to.

BATT_MONITOR= 0Verify & justify

The first battery instance is disabled; all battery sensing and every battery failsafe run on instance 2 (BATT2_MONITOR = 4). This is workable but unusual — confirm it matches the wiring diagram, and that no procedure or checklist refers to battery 1.

ADSB_ICAO_ID= 0Verify & justify

ADS-B is enabled (ADSB_TYPE = 1) but no ICAO aircraft identity is set. The transponder will broadcast without a valid identifier. This must be populated from the aircraft registration before flight in controlled airspace.

ARMING_RUDDER= 2Verify & justify

Rudder arming and disarming are both enabled. A full left-yaw stick input at low throttle will disarm the aircraft. Many operators restrict this to 1 (arm only) to remove the in-flight disarm path.

Frozen — sealed at type certification

These define what the aircraft physically is and how it flies: the airframe geometry, the sensor calibrations unique to this unit, the flight-tested control laws, and the certified failsafe and containment behaviour. They are the configuration the type approval is granted against. Any change is an engineering change — it needs an approved deviation, authorised personnel, and re-verification before the aircraft returns to service. In practice this means they should be write-protected in the ground station and covered by a parameter checksum verified at every pre-flight.

Method

Extracted from the PARM records of the dataflash log with pymavlink; where a parameter was written more than once during the session, the last logged value is shown. All 1315 recorded parameters are classified — none are omitted. Values are as flown on 29 August 2026 and describe this airframe; calibration constants, device IDs and usage counters are unit-specific and will differ across the fleet.

This schedule is stricter than the earlier customer-app access policy in the same folder, which classified a 359-parameter subset. The two disagree on 88 parameters — that policy asked which settings a customer could safely be shown, this one asks which settings the type approval depends on. Where they differ, this document is the more conservative reading. A machine-readable copy of this table is written alongside it as Dodo_Parameter_Freeze_List.csv.
